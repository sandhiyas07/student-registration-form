# Student Registration Form

## 📌 Project Overview

The Student Registration Form is a web-based project developed using HTML, CSS, and JavaScript. It allows students to enter their personal and academic details through a simple and user-friendly form.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## ✨ Features

* Student name and email collection
* Phone number validation
* Department and year selection
* Gender selection
* Skills selection
* Address field
* Form validation
* Registration success message
* Responsive design

## 📂 Project Structure

```text
student-registration-form/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Fill in the registration form.
5. Click the **Register** button.

## 🎯 Project Purpose

This project was created to practice frontend web development, form design, input validation, and JavaScript event handling.
